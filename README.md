# opencolibri/starter-dataset-builder

Castor tasks building datasets with AI, from a description or from the catalog of an existing website: `sylius:dataset:build`, `sylius:dataset:images`, `sylius:dataset:export`, `sylius:dataset:delete`. Load them with `opencolibri/starter-fixtures`.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-dataset-builder
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/datasets/build.md) for usage.
